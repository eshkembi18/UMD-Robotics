## Updating a dependency

1. Make a branch.
2. Change the version in the lock file.
3. Re-run the [verification checklist](../quickstart/10-verification.md).
4. If anything changed, update the affected pages and their **Last verified** dates.
5. Open a PR and note the upgrade in the [weekly log](../weekly-log/index.md).
