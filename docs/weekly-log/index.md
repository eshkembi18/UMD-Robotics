# Weekly Development Log

<p class="gr-meta">Maintainer: whole team · Meetings: Wednesdays, 10 AM, in person</p>

A short entry after every Wednesday meeting. It takes about 5 minutes, and it makes the interim and final reports much easier to write.

```bash
python scripts/new_entry.py weekly 2026-11-11
```

That creates `docs/weekly-log/fall-2026/2026-11-11.md` from the [template](../page-templates/weekly-meeting.md) and prints the line to add under **Weekly Log** in `mkdocs.yml`.
