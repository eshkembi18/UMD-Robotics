## Before each session

- [ ] No cracked printed parts
- [ ] Screws tight, especially on servo horns
- [ ] Cables not pinched or strained at the joints
- [ ] Supplies labeled and correct

## Replacing parts

| Part | Procedure | Notes |
|---|---|---|
| Servo | 1. Set up the new servo **on its own** with the old one's ID ([step 3](../quickstart/03-servo-ids.md)). 2. Install it. 3. **Recalibrate** that arm ([step 7](../quickstart/07-calibration.md)) | A new servo won't have our ID |
| Printed part | Reprint using [our settings](printed-parts.md) | |
| Cable | Same type as listed in [Wiring](wiring.md) | |
