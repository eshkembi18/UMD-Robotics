# Decision Record (ADR) Template

Use this for any choice the next team might ask "why did they do that?" about: hardware, guides, training environment, model choice, deployment approach.

````markdown
# ADR-000: Decision title

<p class="gr-meta">Date: YYYY-MM-DD · Status: Proposed | Accepted | Superseded by ADR-XXX · Deciders: names</p>

## Problem

What needed deciding, and why now.

## Options considered

| Option | Pros | Cons |
|---|---|---|
| A | | |
| B | | |

## Criteria

What mattered: cost, time, reliability, team experience, client requirements…

## Decision

What we chose.

## Rationale

Why, tied to the criteria.

## Tradeoffs & consequences

What we gave up. What this commits us to.

## Evidence

Links: experiments, benchmarks, docs, discussions.
````
